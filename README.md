# Zikirmatik — Gizlilik Politikası

Bu depo yalnız **Zikirmatik** uygulamasının gizlilik politikası sayfalarını
barındırır (GitHub Pages). Uygulamanın kaynak kodu ayrı ve gizli bir depoda
durur; buradaki sayfaların kaynağı orada `docs/privacy/` altındadır ve
değişiklikler oradan buraya kopyalanır.

- Türkçe: <https://selmantncr.github.io/zikirmatik-privacy/>
- English: <https://selmantncr.github.io/zikirmatik-privacy/en/>
- العربية: <https://selmantncr.github.io/zikirmatik-privacy/ar/>
